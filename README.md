#### About

2009年からフルスタック開発に従事。Python（Flask / PyWebIO / Streamlit）、JavaScript（ES6+）、MySQL などを活用。2014年に起業し、投資を獲得。チームマネジメントとプロジェクト実行の経験を持つ。書籍出版と映像作品の脚本・制作も携わる。

現在：フルスタック開発 / 書籍執筆 / 脚本制作
