## 自己紹介

2009年からフルスタック開発に従事。Python（Flask / PyWebIO / Streamlit）、JavaScript（ES6+）、MySQL などの技術スタックを活用。2014年に起業し、投資を獲得。チームマネジメントとプロジェクト実行の経験を持つ。書籍出版と映像作品の脚本・制作にも携わる。

- 現在：フルスタック開発 / 書籍執筆 / 脚本制作
- 学習中：日本語 / 自然言語処理 / 映像制作
